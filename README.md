## Features

* Responsive layout for mobile and desktop screens
* Animated result scores
* Dynamic summary data loaded with JavaScript

## Built With

* HTML5
* CSS3
* Vanilla JavaScript

## What I Learned

While building this project, I practiced:

* Starting the layout with a mobile-first approach, using percentages rather than fixed values (px), and defining the required containers to organize the content
* Positioning elements relative to one another
* Using gradient colors
* Structuring HTML for maintainability and readability
* Using JavaScript to add interactive elements
* Fetching data from a JSON file and dynamically adding it to the page
* Using JavaScript to manipulate HTML elements and animate score values

## Challenges

One of the biggest challenges was making sure all the elements aligned correctly and were centered on the page.

The design required me to explore different approaches and possible solutions.

I had to analyze how each element, `div`, and `section` interacted with the others.
